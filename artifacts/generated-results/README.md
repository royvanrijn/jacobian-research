# Generated artifacts

## Local heavyweight generation cache

`artifacts/generated-results/` is for compact, intentionally pinned reference
artifacts only.  Restartable checkpoints, raw Singular certificates, solver
transcripts, and other large intermediates belong in the ignored
`artifacts/local/` cache.  Regenerate the rank-two divergence material with
`make generate-rank-two-divergence-local`; set
`LOCAL_CERTIFICATE_CACHE=/path/to/cache` to use another local location.
The leading characteristic-zero descent level is generated by
`make generate-rank-two-char0-leading-local`.

Do not move a local cache file into this directory merely to preserve it.
Promote only a compact manifest or independently checkable reference artifact,
and document the exact command and whole-file SHA-256.

This directory contains reproducible outputs from retained research
computations.  Only outputs with a named generator and verification path below
are treated as reference artifacts.
