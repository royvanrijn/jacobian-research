# Double-conic invariant-saturation gate

## Status

This note proves `HC4NHM21`.  It formulates the double-conic invariant-ring
elimination with the necessary clean saturation and shows that the tempting
unsaturated discriminant certificate is false.  It also separates the
squarefree target from the full GIT-stable target.  It does not compute the
final invariant elimination and does not close the support-at-least-five
branch.

Replay the exact lower-Smith example with

```bash
.venv/bin/python scripts/verify_hc4_double_conic_invariant_saturation_gate.py
```

## 1. The covariant ideal

Use the harmonic splitting of `HC4NHM15`:

\[
 h_5=H_5(f)+qH_3(g)+q^2H_1(k),
 \qquad
 (f,g,k)\in S^{10}U\oplus S^6U\oplus S^2U.
 \tag{1.1}
\]

Write \(A\) for the polynomial ring on this representation.  Let
\(I_{\mathrm{nor}}\subset A\) be generated by every coefficient of

\[
 \Phi_{18},\qquad\Phi_{14},\qquad\Phi_{10},\qquad\Phi_6.
 \tag{1.2}
\]

Then \(V(I_{\mathrm{nor}})\) is exactly the locus

\[
 q^4\mid\det\operatorname{Hess}(h_5).
 \tag{1.3}
\]

Let \(\phi_{2,0},\phi_{2,1},\phi_{2,2}\) be the three coefficients of the
remaining binary quadratic \(\Phi_2\), and put

\[
 \mathfrak m_2=(\phi_{2,0},\phi_{2,1},\phi_{2,2}).
 \tag{1.4}
\]

The clean nonzero-line locus is not all of (1.3); it is

\[
 V(I_{\mathrm{nor}})\setminus V(\mathfrak m_2).
 \tag{1.5}
\]

Its scheme-theoretic closure is therefore defined by

\[
 \boxed{
 J_{\mathrm{clean}}
 =I_{\mathrm{nor}}:\mathfrak m_2^\infty.
 }
 \tag{1.6}
\]

This is the saturation that must precede elimination of \(g\) and \(k\).

## 2. Why unsaturated discriminant membership is impossible

Take

\[
 h_5=x^5+z^5.
 \tag{2.1}
\]

Its Hessian matrix has a zero \(y\)-row and \(y\)-column, so

\[
 \det\operatorname{Hess}(h_5)=0.
 \tag{2.2}
\]

On the conic \((x,y,z)=(s^2,st,t^2)\), its binary-decic restriction is

\[
 f=s^{10}+t^{10},
 \tag{2.3}
\]

which is squarefree in characteristic zero.  In the normalization used by
the checker,

\[
 \operatorname{Disc}(s^{10}+1)=-10^{10}\ne0.
 \tag{2.4}
\]

The unique harmonic decomposition of (2.1) supplies correction forms
\((g,k)\) for which all five Hessian layers vanish:

\[
 \Phi_{18}=\Phi_{14}=\Phi_{10}=\Phi_6=\Phi_2=0.
 \tag{2.5}
\]

Consequently, for every \(N>0\),

\[
 \boxed{
 \operatorname{Disc}(f)^N\notin I_{\mathrm{nor}}.
 }
 \tag{2.6}

This is a lower-Smith zero-residual-line point, not a clean survivor.  It is
removed by (1.6).  Any certificate written before that saturation is simply
false.

## 3. The exact squarefree certificate

Let \(B=K[S^{10}U]\) be the coefficient ring of the decic.  The correct
elimination ideal is

\[
 E_{\mathrm{clean}}=J_{\mathrm{clean}}\cap B.
 \tag{3.1}
\]

A certificate

\[
 \boxed{
 \operatorname{Disc}(f)^N\in E_{\mathrm{clean}}
 }
 \tag{3.2}
\]

would exclude every **squarefree** binary decic from the clean double-conic
packet simultaneously.  Equivalently, it would show that every clean
normal-layer solution projects into the discriminant divisor.

Because (1.2), (1.4), and (1.6) are \(SL_2\)-stable, the contraction (3.1)
can be computed in the binary-decic invariant ring

\[
 R=B^{SL_2}
 \tag{3.3}
\]

after Reynolds projection or an invariant-ring presentation.  This is the
precise invariant replacement for further root specializations.

## 4. Why the discriminant does not close every stable decic

For a binary decic, GIT stability means that every root has multiplicity
strictly less than five.  Stable forms may still have repeated roots.  For
example,

\[
 s^2t(s-t)(s-2t)\cdots(s-7t)
 \tag{4.1}
\]

has degree ten and maximum root multiplicity two, so it is stable, but its
discriminant is zero.  Thus (3.2), even if proved, closes only the
squarefree open.

To close the complete stable locus in one invariant calculation, let
\(R_+\) be the positive-degree ideal of \(R\).  Its zero set is the binary
decic nullcone, equivalently the forms with a root of multiplicity at least
six.  A strong sufficient target is

\[
 \boxed{
 R_+\subset\sqrt{E_{\mathrm{clean}}\cap R}.
 }
 \tag{4.2}
\]

It is enough to choose a homogeneous system of parameters
\(\eta_1,\ldots,\eta_r\) for \(R\) and certify

\[
 \eta_i^{N_i}\in E_{\mathrm{clean}}
 \quad(1\le i\le r).
 \tag{4.3}
\]

Then every clean solution has unstable decic restriction, so every stable
many-root decic is excluded at once.  A catalecticant consequence is useful
only if its vanishing is proved to imply the same nullcone containment; a
single discriminant or catalecticant equation does not do so automatically.

## 5. Result and next computation

> **Theorem `HC4NHM21` -- Double-conic invariant-saturation gate.**  The
> clean correction-form elimination is governed by the saturated ideal
> (1.6).  No power of the binary-decic discriminant belongs to the
> unsaturated four-layer ideal, as witnessed by (2.1)--(2.5).  After clean
> saturation, discriminant membership has exactly the squarefree meaning
> (3.2), while nullcone containment (4.2) is the correct simultaneous target
> for all GIT-stable decics.

The next calculation is now unambiguous: construct
\(E_{\mathrm{clean}}\cap R\), first test (3.2), and then test a homogeneous
system of parameters as in (4.3).  Failure of (3.2) after saturation would
produce a genuine squarefree normal-layer survivor that must be passed to
the Schur equations; the lower-Smith family (2.1) is not such a survivor.
