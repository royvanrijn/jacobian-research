## What is now closed, and what should replace it

This closes the eligible retained early norm pool as a source of additional
strict classes. It is stronger than a timeout or a sparse unsuccessful
sample: all products in the specified dictionary are excluded modulo G by
an exact kernel certificate. It remains a negative result about the
constructor, not about the fibre's incidence or rational solubility.

The lesson is to stop measuring principal-relation yield as though it were
additional class yield. A relation matrix useful for upper bounds can have
almost no parity dependencies that construct unramified classes, and the
remaining dependency can be generic. No new rank feature or visibility
score is justified by these counts.

The next priority is a **fixed-cubic solubility control**, rather than another
enlargement of this dictionary. The +6 reference now has conditional c_S=12
and an inherited minus-one CT switch of rank6. Check, using equations only,
whether the original and minus-one twist have the same complete S and the
same local-boundary upper bound. If they do, the shared class bound can turn
the switch into a full rank upper bound on the twist and a strict-rational
dimension comparison. This would isolate a simultaneous solubility change
while holding strict incidence fixed. It would still be a quadratic-twist
control, not a condition on the K3 family parameter t or a solution to the
fresh +10/+11 discrimination problem. Those transfer implications would
remain to be proved.
