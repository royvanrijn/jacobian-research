# Structural-search groundwork

Status: exact reusable groundwork and deterministic task manifests. This note
contains **no new Selmer, class-group, Picard-rank, rational-point, or
Mordell--Weil-rank theorem**.

The previous search programme is strong at three things:

1. manufacturing conductor-friendly specializations;
2. finding rational points in many coordinate charts; and
3. certifying independence once a promising point set exists.

Its recurring failure mode is that expensive searches return many points in a
subgroup already known. The structural layer added here moves quotient,
Selmer, surface-lattice, and cover information earlier in the pipeline.

The pinned manifest is
[`elliptic_structural_search_groundwork.json`](../../artifacts/generated-results/elliptic_structural_search_groundwork.json).
It is generated by
[`build_structural_search_groundwork.py`](../cas/build_structural_search_groundwork.py)
and checked by the two focused regression suites.

## 1. Finite-quotient escape as a search objective

[`finite_quotient_escape.py`](../cas/finite_quotient_escape.py) consumes the
same exact rows used by the existing finite-reduction independence
certificates. Fix a prime \(\ell\), a certified subgroup \(G\), and good-prime
reduction maps into

\[
  \prod_p E(\mathbf F_p)/\ell E(\mathbf F_p).
\]

For a candidate point \(P\), if adjoining its column increases the exact
\(\mathbf F_\ell\)-rank over the image of \(G\), then

\[
  P\notin G+\ell E(\mathbf Q),
\]

and in particular \(P\notin G\). This is a strong positive filter. Failure to
escape is not a dependence proof: the selected finite quotients can miss a
new rational direction.

The API supports:

- arbitrary prime moduli, not only the current mod-2 certificates;
- individually order-independent escape tests;
- deterministic extraction of an independent candidate subset;
- stacking many good-prime blocks; and
- a multi-modulus priority key across \(\ell=2,3,5,\ldots\).

The first calibration is real rather than synthetic. The pinned mod-5 cyclic
log matrix for the canonical rank-20 Fermigier--Mestre candidate has rank 12
on its first twelve basis columns and rank 20 after the remaining eight
columns are adjoined. Each of those eight columns individually escapes the
12-column prefix image. This does not identify that prefix with the generic
subgroup; it verifies that the adapter can prioritize exact quotient gain on a
known high-rank certificate.

**Integration rule:** every point-producing search should calculate quotient
escape before raising point height, running saturation, or requesting a long
descent. Raw point count becomes a secondary statistic.

## 2. Residual 2-Selmer and the 2-division cubic

[`structural_search.py`](../cas/structural_search.py) constructs the exact
primitive 2-division cubic for any generalized Weierstrass model
\([a_1,a_2,a_3,a_4,a_6]\):

\[
  4x^3+b_2x^2+2b_4x+b_6,
\]

where

\[
  b_2=a_1^2+4a_2,
  \qquad b_4=a_1a_3+2a_4,
  \qquad b_6=a_3^2+4a_6.
\]

For the canonical rank-20 minimal model, the pinned primitive ascending
coefficients are

```text
[14347368867288662451721059640396307206349152509,
 -17749648240442974566100980457218,
 5,
 4]
```

This is the exact cubic-algebra input for the missing class-group/Selmer lane.
It is not itself a class-group computation.

`ResidualSelmerBudget` keeps the logical roles separate. If
\(s=\dim_{\mathbf F_\ell}\operatorname{Sel}_\ell(E)\) and
\(t=\dim E(\mathbf Q)[\ell]\), then

\[
  \operatorname{rank}E(\mathbf Q)\le s-t.
\]

After a known free subgroup of rank \(r\), the remaining
\(s-r-t\) Selmer dimensions may represent additional Mordell--Weil classes,
\(\Sha[\ell]\), or both. A positive residual dimension is therefore a cover
search queue, not a rank lower bound.

The first external task, `R20-RESIDUAL-2SELMER`, requires:

1. the complete 2-Selmer dimension and rational 2-torsion dimension;
2. the cubic field and its 2-primary class-group data;
3. Kummer images of all twenty pinned generators;
4. explicit residual locally soluble covers; and
5. minimized/reduced models for only those unexplained classes.

This replaces an undirected `ell2cover(E)` call with a relative computation
against the known rank-20 subgroup. A residual cover with a rational point is
the most direct possible route to the twenty-first generator. If the Selmer
upper bound is 20, the fixed fiber is closed unconditionally.

Primary algorithmic precedents include the high-rank exact-rank work of
Klagsbrun--Sherman--Weigandt and minimization/reduction of 2-, 3-, and
4-coverings by Cremona--Fisher--Stoll.

## 3. Néron--Severi lattice search on the Fermigier K3

The current function-field search guesses formulas for \(x(T)\). A
multisection can be simple in the Néron--Severi lattice and ugly in that
coordinate. The exact lattice primitives therefore work with a symmetric
integral Gram matrix directly.

Given a fiber class \(F\), the bounded enumerator retains primitive classes
\(D\) with prescribed

\[
  D\cdot F=d,
  \qquad D^2=2g-2.
\]

On a K3 surface the second equality is the adjunction arithmetic genus. The
same module enumerates primitive positive isotropic vectors \(D^2=0\), which
are candidates for alternate elliptic fibrations.

This is deliberately only the first layer. A retained vector must still pass:

- saturation/overlattice checks for the known NS sublattice;
- effectiveness and nefness;
- irreducibility and field of definition;
- reconstruction of an actual divisor or multisection; and
- specialization/quotient escape if it produces a section after base change.

The initial task `FERMIGIER-NS-LATTICE` starts from the known arithmetic
rank-17 divisor sublattice: trivial lattice rank 5 plus Mordell--Weil rank 12.
Its first target is fiber degree 2--4 and small self-intersection. The more
ambitious target is an alternate fibration in which an otherwise hidden
multisection becomes an ordinary section.

The implementation includes only a hyperbolic-plane regression fixture until
the actual section-height/NS Gram matrix is exported from the generic-rank
certificate. It will refuse to present fixture vectors as Fermigier divisor
classes.

## 4. The \(V_4\) pair-cover decomposition

For a genuine pair cover

\[
  y_1^2=f_1(T),
  \qquad y_2^2=f_2(T),
\]

the structural module represents each quadratic character by its branch
divisor on \(\mathbf P^1\). The third character is the symmetric difference
of the first two branch sets, corresponding to \(f_1f_2\) modulo squares.

For the disjoint sextic/sextic calibration occurring in the Fermigier
transport search, the three quotient genera are

\[
  (2,2,5),
\]

and the connected \(V_4\)-cover has genus

\[
  2+2+5=9.
\]

This records the Kani--Rosen dimension decomposition

\[
  J(C)\sim J(C_1)\times J(C_2)\times J(C_3)
\]

at the level needed to launch downstream work. It does not determine
\(C(\mathbf Q)\).

`FERMIGIER-V4-PILOT` chooses one of the 3,160 exact pair covers and requires:

- pinned quotient equations;
- Jacobian models for the two genus-2 and one genus-5 quotients;
- Selmer/rank bounds and images of the two prescribed anchors;
- a Chabauty or Mordell--Weil-sieve plan with explicit local data.

The success condition is intentionally sharp: either determine all rational
points on one pair cover or find a third point. Another raw height extension
is not the intended output.

## 5. Quadratic twist characters, not division of old sections

For a quadratic extension \(K=\mathbf Q(T)(\sqrt{d(T)})\), the useful
anti-invariant rank contribution comes from the quadratic twist:

\[
  \operatorname{rank}E(K)
  =\operatorname{rank}E(\mathbf Q(T))
  +\operatorname{rank}E^{(d)}(\mathbf Q(T)).
\]

The twist groundwork records the complete branch divisor of \(d(T)\), hence
the genus and complexity of the base change. The initial engine is restricted
to at most eight branch places, then applies:

1. singular-fiber and conductor-geometry inventory;
2. an early Frobenius/Picard upper filter;
3. exact section elimination on \(E^{(d)}\); and
4. specialization escape against the old subgroup.

A point \(S\) satisfying \([n]S=R\) for an existing section \(R\) improves
saturation but does not increase rank. The manifest explicitly rejects that
as a success condition.

## 6. Projective p-adic balls and the fiber at infinity

The existing conductor search mostly uses finite affine roots with denominator
a \(p\)-adic unit. `ProjectivePadicBall` treats both charts of
\(\mathbf P^1(\mathbf Q_p)\):

- affine coordinate \(T=a/b\):
  \(a-rb\equiv0\pmod {p^k}\), with \(b\) a unit;
- infinity coordinate \(S=b/a=1/T\):
  \(b-ra\equiv0\pmod {p^k}\), with \(a\) a unit.

Residue zero in the second chart is a genuine neighborhood of infinity.

`projective_congruence_lattice` combines one compressed ball per prime into a
single homogeneous congruence

\[
  Aa+Bb\equiv0\pmod M
\]

and constructs an exact rank-two integral basis. The mixed-chart fixture

```text
b = 0 mod 5,
a - 3b = 0 mod 7
```

has lattice basis

```text
(7,0), (1,5)
```

and index 35. The projective point \((1:5)\) satisfies both chart conditions.
This is the missing algebraic frontend for denominator-divisible local
searches near Fermigier's split \(I_4\) infinity fiber. Every reconstructed
specialization must still be globally minimized before conductor conclusions
are drawn.

## 7. Algebraic Mestre moduli, isogeny hopping and early Picard filters

Three lanes are represented by strict external task schemas rather than fake
pure-Python implementations:

- `MESTRE-MODULI-COMPONENTS`: primary decomposition of the Mestre
  obstruction, companion-section and split-infinity equations over several
  finite fields, followed by characteristic-zero lifting and rational
  parametrization;
- `ISOGENY-HOPPING`: complete rational isogeny graphs, explicit maps, and
  point/descent work on every isogenous model while retaining the invariance
  of rank and conductor;
- the Frobenius/Picard gate inside the NS and twist tasks: count the surface at
  one or more good primes before investing in large section or specialization
  searches.

The task schema records exact inputs, acceptable engines, required outputs,
success gates and claim boundaries. A timeout or a finite-field component is
stored as such; neither becomes mathematical evidence by wording.

6. `ISOGENY-HOPPING`;

This order is not a mathematical claim. It reflects expected information gain
per expensive CAS call. The first three can close a major branch or expose a
specific missing class; the later lanes enlarge the construction space.
