Standard generators

Standard generators of A7 are a, b where a is in class 3A, b has order 5 and ab has order 7.

Standard generators of 2.A7 are preimages A, B where A has order 3 and B has order 5. Alternatively: A has order 3 and AB has order 7 or A has order 5 and AB has order 7.

Standard generators of 3.A7 are preimages A, B where B has order 5 and AB has order 7.

Standard generators of 6.A7 are preimages A, B where B has order 5 and AB has order 7.

Standard generators of S7 are c, d where c is in class 2B, d is in class 6C and cd has order 7.

Standard generators of 2.S7 are preimages C, D where CD has order 7.

Standard generators of 3.S7 are preimages C, D where CD has order 7.

Standard generators of 6.S7 are preimages C, D where CD has order 7.

Standard generators of 2.S7 (isoclinic) are preimages C, D where CD has order 7.

Standard generators of 6.S7 (isoclinic) are preimages C, D where CD has order 7.
