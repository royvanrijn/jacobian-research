# Affine-type rulings descend

On every proper native Keller intermediate, a geometric affine-type A1-ruling is UNIQUE, descends to the retained field, and gives a retained-field additive action. The proof uses the actual canonical volume, a published classification and an explicit weighted Galois trace. It does not assume ruling invariance.

- [General proof](PROOF.md): UAMLFACTOR1 identifies trivial geometric ML exactly with target-factor invertibility; UAAFFDESC1 proves uniqueness and constructive descent.
- Assuming JC(2), only additively rigid intermediates with Galois-permuted COMPLETE-type rulings remain. Their descent is open.
- Averaging distinct rulings fails even on the plane: an explicit conjugate coordinate pair has trace with generic fibre Gm.
