# Selector rigidity and classical field tools

Reviewed 15 November 2026. [Written proof](PROOF.md), [source pins](sources.json). No publication novelty is claimed.

UARANKONE1 already reduces an arbitrary compiler-source selector to a finite common-kernel problem. The extension here computes that kernel without any degree bound, using a leading auxiliary monomial, rational sign symmetries and a two-dimensional commutator determinant. These are deductions for the retained compiler, not a universal result about arbitrary polynomial vector fields.

The [Stacks Kummer section](https://stacks.math.columbia.edu/tag/09I6) provides classical quadratic-extension context. The proof establishes square-class independence directly: distinct linear t-factors each have an odd valuation in any nonempty product. [Lemma 10.47.12](https://stacks.math.columbia.edu/tag/0G33) relates geometric irreducibility to relative algebraic closedness. Together with the elementary characteristic-zero derivation argument, this makes each rational first integral even in the active r coordinates. No complete additive action or local nilpotence is assumed.

The [smooth-morphism section](https://stacks.math.columbia.edu/tag/01V4) supplies composition and flatness for the regular-descent step. The signal projection has relative dimension two per active block, so its use must not be confused with the earlier one-dimensional auxiliary quotient. Flat going-down handles divisors in either relative dimension.

UAPARALLEL1 constructs the actual partial polynomial maps; UAALLATOM1 is used only to identify the displayed N+1-stage cubic chain as atomic. No group classification or imprimitive-field algebraization is substituted for those explicit maps. For a different auxiliary block, UAGEOMFEED1 output recovery remains a separate exact hypothesis, linked in the earlier source to generalized Jacobian closed-subring assertions.

The former suggestion to seek a separating invariant beyond active signals is now ruled out for polynomial selectors in the compiler source alone. Selectors depending jointly on compiler and auxiliary sources, genuinely higher-rank return, nonpolynomial profiles with a new landing proof and different compilers remain outside. No absolutely atomic canonical map is constructed. No new external AI-assisted theorem was required; independent review and publication-priority research remain outstanding.
