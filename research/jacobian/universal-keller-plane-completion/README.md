# Profile-factor rigidity and the generic plane completion

A native polynomial Keller map recoverable through ANY retained profile is already its explicit target shear b->b+a^5*c^3*h. No nontrivial target factor can follow that profile. This uses the published plane line-injectivity theorem, already imported elsewhere in this repository.

- [General proofs](PROOF.md): profile-factor rigidity, the exact plane-completion ring, leading-divisor gates, and a general indecomposability theorem for plane maps with irreducible Jacobian and an embedded line.
- Every native polynomial-r completion has Jacobian 1-SY and is plane-indecomposable. The [embedded-curve extension](../universal-keller-intermediate-surfaces/PROOF.md) now removes that boundary-extension hypothesis and closes EVERY signal-retaining whole factorization, including negative Laurent-r sectors. This is not full or stable atomicity of the original Keller map.

The earlier saturation assertion has explicit public precedent in Trushin's 2026 preprint under a weaker hypothesis. Independent proof review, novelty assessment, polynomial integration and canonical absolute atomicity remain open.
Under arbitrary identity stabilization and intermediate coordinate mixing, the new theorem applies to the actual generic retained fibre. A noninvertible target factor requires that surface to be NON-PLANE, with the exact unit, carried-component, divisor and saturated-field constraints. Full stable atomicity and global realization of a proper intermediate remain open.
