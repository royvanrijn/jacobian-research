# A proper intermediate has no nonconstant geometric units

For ANY whole Keller map (u,sigma,B,C) with the fixed source signal, a factorization F=E composed G has nonconstant intermediate generic units exactly when G is an automorphism. This includes arbitrary identity stabilization and intermediate coordinate mixing; the last two outputs need not be native.

- [General proofs](PROOF.md): primitive-unit rigidity for cofinite etale maps from the hyperbola complement, published root descent, the whole-factor unit criterion and the complete intermediate signal fibre pattern.
- A proper intermediate is now geometrically unit-free; in the native case it must also be non-plane. Its generic ring is factorial over k(u,a). The [log-Picard extension](../universal-keller-log-picard/PROOF.md) now proves negative log Kodaira dimension and NONZERO geometric Picard group with ZERO retained-field Galois invariants for a proper native factor. Its whole signal component has no reducible constant fibre.
- All-degree generic self-maps demonstrate why primitive unit pullback and the retained node cannot be omitted.
