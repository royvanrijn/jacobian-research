# Jacobian and Keller maps

We investigate polynomial maps with constant nonzero Jacobian, their boundary geometry, and universal Keller constructions.

**Closed within stated scopes:** explicit fibre constructions, degree-specific obstructions and restricted boundary branches. These are intermediate results; the full Jacobian conjecture remains open.

**Open:** global coverage, stable descent, monodromy and moduli questions, and the remaining plane-boundary cases. Use the [ledger](../MATH_STATUS.json) for the exact hypotheses.
