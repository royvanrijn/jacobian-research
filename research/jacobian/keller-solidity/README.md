# Solidity and global regularization obstructions

A nonzero global target-linear functional for a generically finite domain extension already forces module finiteness. The main implication is classical solidity, independent of dimension, characteristic, smoothness and the Keller condition. A short pairing proof replaces the longer derivative argument used in the public JC2 campaign.

The [proof](PROOF.md) also excludes every finite-order differential operator from a nonfinite extension into a finite torsion-free target. On the actual Wright inclusion, this rules out all finite-order global regularization into the normalization ring, in every degree. It does not exclude a Keller pair by itself.

- FINSOL1: characteristic-free finiteness criterion and determinant denominator bound.
- FINSOL2: finite torsion-free targets and finite-order differential operators.
- WRIGHTSOL1: the actual Wright source inclusion has zero global dual and no finite-order regularization.
