# Historical K3 equation-recovery data

This directory retains early graph constraints and system summaries. Its old
placeholder `elkies-rank17.json` was never the canonical endpoint model.
The rational MW17 equations and full section bases are already available in
the [K3 programme](../../README.md) and the
[direct alternate11952 fibration](../../R17_NORM12_ORBIT11952_DIRECT_FIBRATION_2026-09-03.md).
Use their exact loaders and certificates instead of reconstructing a model
from these historical constraints.

The historical coefficient convention is `[c0,c1,c2,...]` for
`c0+c1*t+c2*t^2+...`. The original model-placeholder note is preserved in the
[cleanup snapshot](../../../archive/repository-cleanup-2026-09-12/research__elkies-k3__data__k3-model__README.md.txt).
