## Explicit identities through mixed acquisitions

In the residual-strict-07 run, denote its initial quotient seed by s=R7 and its
successive **original signed** acquired quotient vectors by v1,v2,... . The
certificate gives:

```text
L1 = s - 2*v1 + v2 + v3        (r=4)
L2 = -v3 + v5                 (r=6)
L4 = v1 - v2 + v3 - v5       (r=6)
```

Thus these underlying directions are reconstructed even when the newly found
points are mixed. Every equality is exact in D/M17. For each named axis and
each common basis row, the certificate records a word in the initial seed and
the acquired points; no numerical height recognition is used by this audit.
Recovering the generic M17 correction as an explicit 17-component word would
require the full point coordinates from the earlier EC reconciliation, beyond
these quotient identities.

## Verification and execution ledger

The [runner](../cas/run_curve302_exact_core.py) uses exact rational solves,
Smith forms and integer-module intersections. Five focused regressions cover
the example <(1,2)> versus <(1,0)>, rational-only membership with least multiple
15, integral reconstruction from mixed words, nonsaturated lattice
intersections, and coefficients beyond floating-point integer precision.

The [separate verifier](../cas/verify_curve302_exact_core.py) reconstructs the
prefixes from the hash-bound prior trajectory export, checks all integer
identities, and computes common rational spaces by stacking annihilator
equations. Since each prefix is saturated in Z^14, their integral intersection
is the saturated lattice in that rational intersection; the verifier checks
this saturation and completeness as well as the full mod-2 lift.

From the repository root:

```sh
sage -python -m unittest discover -s research/elliptic-curves/tests \
  -p test_curve302_exact_core.py -v
sage -python research/elliptic-curves/cas/verify_curve302_exact_core.py
sage -python research/elliptic-curves/cas/run_curve302_exact_core.py check \
  --folder research/artifacts/local/elliptic-curves/curve302-exact-core-v2
```

All five tests pass. Deterministic recomputation and the separate annihilator
and integer-witness replay pass for all fourteen runs and 194 prefixes.
Neither check repeats the original elliptic-curve coordinate proofs.
