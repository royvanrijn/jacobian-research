# Exact ranks of the specialized generic-section spans

The [endpoint audit](COMPACT_ENDPOINT_AUDIT_2026-09-06.md) left a distinction
open: its finite lower bounds did not establish dependence among the other
specialized sections. The [exact relation certificate](../../artifacts/generated-results/elliptic-curves/endpoint_section_relations_v1.json)
now closes that distinction on all 21 nonsingular endpoints. Nineteen lose
independence. These are ranks of the groups generated by the displayed
sections, not whole-curve ranks.

For each endpoint, let `P_1,...,P_r` be its independently certified subset.
For every original section value `Q`, the certificate gives integers `d > 0`
and `c_i` and verifies exactly

```
d Q = c_1 P_1 + ... + c_r P_r.
```

Thus all section values lie in the rational span of those `r` independent
points, proving both bounds for this particular subgroup. The proposer uses
384-bit numerical canonical heights and rational approximation with denominator
and integer coefficient bounds 64. Its output has no proof authority until
ordinary Python rational group arithmetic verifies every relation. Numerical
heights do not enter the exact checker. All 21 proposed spans pass both build
and replay; there are no unresolved section values in this bounded attempt.

## An independent subset can omit part of the known subgroup

The [exact lattice-index audit](../../artifacts/generated-results/elliptic-curves/endpoint_section_lattice_indices_v1.json)
uses these rational coordinates and a verified unimodular Hermite
transformation. After quotienting torsion, five certified subsets have proper
index in the subgroup generated by all known section values:

| Endpoint | Index |
| --- | ---: |
| 103b2 infinity | 5 |
| 074d9 zero | 3 |
| 07ca9 infinity | 5 |
| 08234 infinity | 5 |
| 08f72 infinity | 3 |

All other indices are one. This is an exact comparison of two explicitly
known groups. It does not saturate either group inside the whole Mordell–Weil
group, nor does it add independent directions.

The indices here are odd. Consequently the inclusion of the smaller free
lattice induces an isomorphism modulo two: if `N` has odd index in `M`, then
`N + 2M = M` and `N intersect 2M = 2N`. The omitted section values therefore do
not by themselves supply extra parity dimensions. They can change the integral
lattice and the metric representatives used in a bounded point search. Whether
that improves detection requires a separate comparison.

The frozen endpoint point trial uses its original certified subsets and is
not retrospectively changed by this audit. Its target, bounds and sampled
charts remain those recorded in its protocol. None of these section-span or
index statements excludes additional points on the endpoint curves.
