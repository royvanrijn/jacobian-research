Standard generators

Standard generators of A8 = L4(2) are a, b where a is in class 3A, b has order 7, ab has order 6 and abb has order 15.

Standard generators of 2.A8 are preimages A, B where A has order 3 and B has order 7.

Standard generators of S8 = A8:2 are c, d where c is in class 2C, d has order 7 and cd has order 8.

Standard generators of 2.S8 are preimages C, D where D has order 7.

Standard generators of 2.S8 (isoclinic) are preimages C, D where D has order 7.
