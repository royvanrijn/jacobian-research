# Closed plane-JC branches

These notes are intermediate derivations for the no-vertical `(72,108)`
Laurent branch.  Their finite Belyi deformation problem was completed and
promoted as `PJ72B1` in
[`plane-jc/JC2_72_108_BELYI_DEFORMATION_CLOSURE.md`](../../plane-jc/JC2_72_108_BELYI_DEFORMATION_CLOSURE.md).

The dual-Schur curvature note is a scoped side observation retained with the
derivation that used it; it does not prove `JC2` or a general HC4 descent.
Nothing in this directory is an active proof dependency.
