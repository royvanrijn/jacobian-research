retained stages. It includes the early relation searches and their available
replays, nine initial target waves, failed BNF attempts, the fixed target wave,

This is an incomplete subtotal. Cold factorization and prime proofs, some

lack a complete common meter. Implementation time is another separate item.
The audit does not convert an absent timing into zero or equate wall time with
CPU time. The later 18.401-second cover recovery is not a constructor budget.

The original [design record](../../artifacts/generated-results/elliptic-curves/fresh_constructor_transfer_v1/design.json)
is historical. The approved rule is now fixed: both reference routes receive at
most 7,200 charged seconds. Class commissioning starts cold from the equation
and generic subgroup, including fresh rank admission and complete arithmetic
preparation. A successful independently verified class-to-point rank gain is
required before any fresh fibre starts. A failed or censored reference run does
not supply `C` and cannot trigger a larger allowance.

**The staged stopping rule is executable and frozen.** Let `C` be the complete
measured reference class cost, including retained failed launch costs and the
post-seal union certificate. Freeze `B=min(2*C,7200)` seconds for each route on
each fresh fibre. Run `fresh-01` and `fresh-02` in the fixed order, both routes.
Proceed to the remaining six only if that first pair contains at least one
independently verified fresh class, blind lift and rank gain. Otherwise stop.
The first stage costs at most twelve worker-hours; all nine paired cases cost
at most 36. The fixed roster is never replaced.

One local worker and one local thread run at a time, pinned to a fixed available
CPU, with 2 GiB RSS and a 256 MB PARI stack ceiling. Per-stage supervised wall
and process-tree CPU are recorded separately; orchestration overhead and failed
stages count. Class preparation/construction reserves time for independent
verification and lifting. The first two retained classes receive equal shares
of remaining lifting time, without replacement. V3 has its own independent
preparation, finite bank, search and replay within the same route allowance.

Remote Magma reduction uses the standard public service limits and logs exact
requests, responses, remote reported CPU and full request wall time. Its hardware
and thread allocation are unavailable; local and remote timings do not prove
a hardware-independent speed advantage. All other arithmetic is local. No
full class-group computation is part of either route.

## Separate endpoints

| Stage | Required evidence |
|---|---|
| Arithmetic preparation | Exact field/model transport, certified maximal order and the complete local data used by the constructor |
| Class construction | Explicit factored class, all strict conditions and independent nontriviality modulo the generic span |
| Rational lifting | Exact cover point, cubic-field identity, full transport and original elliptic equation |
| Rank gain | Fresh certificate for the generic sixteen plus the recovered point |
| Ordinary ideal-class gain | Separate half-ideal/Artin detection; the possible unit kernel is not ignored |

Preparation failure, no class within budget, unresolved candidate verification
and unresolved rational solubility must have different ledger states. Stop and
retain completed mathematics at every bound. No enlargement or replacement
is implied by a miss.

V3 starts independently from the same generic subgroup. Seal both outputs
before a comparison worker reads either together. **Transfer success** is a
fresh independently certified class-to-point chain even if V3 finds the same
direction faster. **Complementarity success** requires an additional certified
direction in the combined subgroup beyond V3's sealed matched endpoint. If
the combined independence test is inconclusive, complementarity stays `UNKNOWN`;
matching separate rank totals proves neither dependence nor independence.

All preparation, dependency work, reduction, failures and verification count
towards the class route. Keep remote and local accounting distinguishable.
Eight fibres do not establish a success rate, an infinite-family theorem, or
uniform strict/ordinary ideal-class transfer.
