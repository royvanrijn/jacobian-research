# Bernstein credit, formal extensions and novelty boundaries

This note records the classical inputs used by the current polynomial Gaussian certificate constructions. No novelty or independent review is claimed.

The convergent rational-slope mechanism belongs to classical multivariate
Bernstein theory. In [Sabbah, Proximite evanescente II](https://www.numdam.org/item/CM_1987__64_2_213_0/),
printed214-216, functional equations are controlled by finitely many
primitive nonnegative integral linear forms. The graph/Euler formulation
and componentwise shift equations are already explicit there. His finer
description from characteristic geometry has regularity hypotheses;
those must not be silently applied to an arbitrary Fourier exponential
module.

[Maisonobe, Filtration relative, l'ideal de Bernstein et ses pentes](https://doi.org/10.4171/RSMUP/101),
published2023, printed81-86, credits Sabbah's product of affine linear
forms and identifies a minimal slope set using relative characteristic
varieties. The general holonomic Bernstein-ideal structure and its
regular-holonomic geometric description are distinct assertions.
This is the appropriate provenance for the analytic/convergent slope
mechanism. It should not be described as newly discovered here.

The current first-survival proof provides a separate arithmetic route
from an actual polynomial constraint plus bounded increments to a rational
slope and finite parallel lines. That elementary reproving/application
does not confer priority on the convergent result. Nor do these cited
sources by themselves establish the exact original-power apolar statement
with every scope and coefficient ring used in this repository.

The scope distinctions to preserve are:

| Scope | Treatment and credit |
|---|---|
| Polynomial/convergent Bernstein slopes | Classical Sabbah/Maisonobe mechanism; no novelty claim. |
| Generalized b-function computation, including torsion | Oaku1609.04676, Algorithms3.6-3.8 and Proposition3.7; present code is an application. |
| Current rational finite-input implementation | [Explicit Fourier/graph certificates](OAKU_GRAPH_CERTIFICATES_AND_ACTUAL_POLYNOMIAL_DECISION.md), operators, torsion witnesses and specialization bounds retained; no full actual-image kernel needed. |

The polynomial implementation is an application of these classical inputs.
Independent mathematical review and a full priority comparison are outstanding.
