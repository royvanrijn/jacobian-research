# A proper intermediate's whole curve must cross every plane-chart boundary

Any etale target map from a non-plane surface containing an open A2 would restrict to a JC(2) counterexample. For an actual native intermediate, there is a stronger unconditional obstruction: if the whole carried affine line fits inside ANY plane chart, the target factor is invertible.

- [General proofs](PROOF.md): plane-chart cancellation; standard finite/formal curve neighborhoods despite the global chart obstruction; the classical all-exponent Danielewski atlas; exact Keller gluing identities; a terminating ruling-degree obstruction; root-component contact constraints.
- On u^m*v=P(z), the carried line must meet at least two root components. With N=degree(u on the curve) and r distinct zeros, degree(z)>=mN-r+1. A family attaining the sharp bound fails geometric injectivity for EVERY m>=2.
