# Cyclic companion exclusions across both first-pair parities

15 November 2026. PF2RULED68 removes the odd-first-pair restriction from
the marked cyclic-companion reduction. For an actual primitive-binomial
two-stage quartic branch, every representation with cyclic-order3
companion image is excluded, for ALL coprime first pairs p,q>=2 and all
windings r>=2. Every cyclic-order4 representation is excluded in the
common source pencil. If the even first exponent is divisible by4, it
is excluded in both source pencils. This is a representation-sector
exclusion: a target key may have other, noncyclic representations.

The remaining cyclic-order4 sector has an even first exponent e=2 mod4,
odd exponent o, a complementary source pencil, and gcd(o,r/3)=1.
No claim here closes that sector or the noncyclic companion images.
The entire all-odd class remains closed by PF67.

## 1. Classification using cyclicity, without an exponent search

Use PF63's genuine binomial hypotheses and peripheral words:

    gcd(p,q)=1, c=pq-p-q, k=rc+1,
    <a,b | a^p=b^q>, M=a^u b^v, qu+pv=1,
    L=a^p M^(-pq), h=M^k L^r,
    beta=M^(-c)L^(-1), z^r=h, mu=z beta.

The actual simple quartic monodromy has mu a transposition and
lambda=h mu^(-rk)=1. The number c is odd and rk is even.
Assume ONLY in this section that the companion image is cyclic.
Its abelianization then gives a=M^q,b=M^p and L=1. The whole image
is generated by M and tau=mu, since z=tau M^c. A permutation M of
order at most2 cannot generate S4 with one transposition: two
involutions generate a dihedral group, of order at most8 here.
Consequently M is a 3-cycle or a 4-cycle.

For a 3-cycle, tau must join its three-letter orbit to the fixed
sheet; z is a 4-cycle, so

    C3: 4|r, 3|k.                                           (1)

For a 4-cycle, tau must exchange adjacent letters; an opposite
exchange generates only a dihedral subgroup. Since c is odd, z
has cycle type (3,1), and

    C4: 3|r, 4|k.                                           (2)

In either case all choices are simultaneously conjugate for fixed
M^c and tau: the centralizer of M acts transitively on the permitted
transpositions. These statements cover the entire cyclic companion
sector at arbitrary exponents, not merely examples in PF63's census.

## 2. Pattern homology and marking do not require odd p,q

PF65's integral cyclic-companion replacement applies to any knot and
every finite covering degree. It preserves the ramification mark in
the cable piece and adds the groups H1(Sigma_a(T(p,q))) for the
companion orbit lengths a. Thus the C3 pattern contributes Z/(k/3)
and one triple-cover summand; the C4 pattern contributes Z/(r/3)
and one quadruple-cover summand. The preferred longitude in each
cyclic companion piece is zero, as proved there by a lifted Seifert
surface. No noncyclic piece is replaced.

The C3 calculation in PF65 uses c modulo3, not the parity of p,q.
Its relations, with r=4a,k=3b,d=ac, are

    [[d-b,d],[d,d-3b]],  3b-4d=1.

They give cyclic homology Z/b and h=0. They apply for c=1 or2 mod3;
c=0 cannot satisfy (1). This proves the C3 marking for all first pairs.

For C4 put r=3s,k=4t. PF65 already treats c=4C+3; the other possible
case is c=4C+1 and r=3 mod12. Choose M=(0123),tau=(01),z=tau M.
After collapsing a lifted spanning tree, let A be the fixed z loop,
B its length3 loop, and X=x+y+w the length4 M loop. The exact lifted
root and meridian-filling relations are

    3s A=tX,  sB=tX,
    A=2CX+x,  y=-CX,  B=CX+w.

The last three imply A+B=cX. Adding the first relation to three
copies of s(cX-A)=tX gives (3sc-4t)X=-X=0. Hence A=-B,
sB=0, with no additional relation, and h=3sA=0. The c=4C+3
relations give the same result. Both residue calculations are
unrestricted integer identities; finite controls are not the proof.

Therefore, for ALL coprime first pairs,

    C3: H1(M_end)=Z/(k/3) direct-sum H1(Sigma3(T(p,q))),
    C4: H1(M_end)=Z/(r/3) direct-sum H1(Sigma4(T(p,q))),
    [K_R]=0 in both cases.                                  (3)

The last assertion includes zero coordinates in all companion
summands. It is not inferred from the abstract order of H1.

## 3. Exact cyclic-cover modules across parity

PF65 proves the torus-knot Alexander MODULE is Lambda/(Delta), with

    Delta=(t^(pq)-1)(t-1)/((t^p-1)(t^q-1)).

This derivation does not use parity. Since Delta(1)=1, t-1 is a unit
modulo Delta. For the a-fold cyclic branched cover, replace t^a-1
by P_a=(t^a-1)/(t-1). The triple-cover proof in PF65 therefore gives
for arbitrary coprime p,q

    H1(Sigma3)=0,       if 3 does not divide pq;
               (Z/q)^2, if 3|p;
               (Z/p)^2, if 3|q.                              (4)

For the quadruple cover the all-odd module vanishes, as retained in
PF65. Otherwise write the even exponent e and the odd exponent o.
Set P=P_4=(t+1)(t^2+1), S_o=(t^o-1)/(t-1). Modulo P, S_o is 1
if o=1 mod4, and -t^3 if o=3 mod4. It is a unit, and

    Delta*S_o = S_o(t^e) mod P.

If 4|e, the right side is o. The module is consequently
Z[t]/(P,o), a free rank3 module over Z/o.

If e=2 mod4, the right side is Q=1+b(t^2+1), b=(o-1)/2.
In Z[t]/(P,Q), b(t^2+1)=-1, so t^2+1 is a unit and P forces
t+1=0. Substituting t=-1 gives Q=o. Conversely these substitutions
satisfy both relations. This is an integral ring isomorphism with
Z/o, with no division by2 in Z/o required. Thus

    H1(Sigma4)=Z/o,       if e=2 mod4;
               (Z/o)^3, if 4|e.                              (5)

These full group formulas matter: a group order alone misses the
marked generator obstruction.

## 4. Source consequences and the complete C3 exclusion

For the actual quartic source PF61 and PF65 give canonical covector
(1,0), [K_R] its boundary class, and

    [K_R]=0 ==> H1(M_end) cyclic.                            (6)

The nontrivial square summands in (4) exclude EVERY C3 representation
with 3|pq, including all even first exponents, in either source pencil.
For 3 not dividing pq, the end is the pattern alone in oriented linking:
the cyclic companion piece is an integral homology solid torus, and
PF66's homology replacement preserves that linking and the marking.

Write s=k/3 and t=r/4. The target determinant-square gate gives 9|k,
because r is even; hence s is odd and divisible by3. If 3 does not
divide pq, c is either0 or2 mod3. Condition 3|k excludes c=0 and
forces c=2, r=1 mod3 and t=1 mod3. The primitive relation is
3s-4tc=1, so gcd(3s,4t)=1. PF66's ORIENTED pattern calculation,
which assumes these integers and coprimality but no parity of p,q,
gives linking <-t/s>.

For the full source matrix Q=[[-n_R,c_src],[c_src,-n_D]], zero
ramification mark makes the D class a generator and its self-linking
n_R/s. An oriented isometry therefore implies

    n_R=-t*u^2 mod s, gcd(u,s)=1,
    n_R=2 mod3.                                             (7)

In the complementary source, order1 has cross 2*p_D even, impossible
when detQ=s is odd and n_D is even. At every order r_src>=2,
n_R=r_src^2-r_src+1 is0 or1 mod3, contradicting (7). This is the
same source-wide arithmetic as PF66, now justified for every C3
first-pair parity. In the common source, PF67 requires NONZERO
ramification self-linking, contradicting (3). This closes ALL C3
representations uniformly in p,q,r and every source order/pole.

For C4, (5) excludes 4|e by (6), since o>=3. If e=2 mod4,

    H1(M_end)=Z/(r/3) direct-sum Z/o,

so (6) requires gcd(o,r/3)=1. Every C4 common source is excluded
by PF67 and (3), whatever its first-pair parity. An even-pair C4
representation still requires a complementary source, e=2 mod4,
gcd(o,r/3)=1 and all prior gates (including 9|r*o). These are
necessary conditions, not existence or sufficiency assertions.
