For any target center b, if the actual radial lift E_b preserves a
closed source curve C isomorphic to A1, then F is invertible.

and a Keller map has finite fibers. The closure of F(C) is an
irreducible target curve invariant under the centered ordinary Euler

apply polynomial spectral projections in Euler to the finitely many
homogeneous pieces of each of its elements. Over C a homogeneous
irreducible binary polynomial is linear. Thus F(C) lies on a line
through b.

Since F is etale and C is a closed smooth embedded A1, its restriction
to that line has nowhere-zero derivative. In an A1 parameter it is
a nonconstant polynomial with constant nonzero derivative, hence
linear and injective. The curve is an actual closed A1 component

Consequently a noninvertible actual E_b cannot preserve any source
polynomial-coordinate fibration: there cannot be a source coordinate
u and polynomial a(T) with E_b(u)=a(u).

If a is nonconstant, choose a complex root r; the coordinate line
